# <游戏名> — 术语表与翻译基线（模板）

> 复制成 `localization/glossary.md` 后重写。这是每个项目**唯一需要重写的文本**，
> 也是直接喂给翻译执行者（人或 agent）的**执行契约**——所以它同时承担两件事：
> ① 词表与语域基线；② 输出格式与成本控制条款（§8.1：把契约写进这份共享文件，prompt 只留 6 行）。
> 下面"通用口径"一节是跨项目验证过、可以直接照抄的规则；`<尖括号>` 才是每个项目要填的。

## 硬约束

1. **人名一律保持英文原样**，不音译、不双语化：`<Name1>` `<Name2>` …
   - ✅ `<Name1> 老师`　❌ `<音译>`　❌ `<Name1> / <音译>`
2. **只译对白**。菜单、设置、导航按钮、HUD、图鉴、标题卡一律不译。
3. **要守恒的是标签本身，不是标签里的英文字节**。`{b}` `{/b}` `{i}` `{color=…}` `{/color}`
   `[插值]` 的**数量、顺序、写法**不许变（`apply_trans.py` 按多重集校验），标签**内**的文字分三类处理：

   | 标签里的内容 | 怎么处理 | 例 |
   | --- | --- | --- |
   | 人名 / `[插值]` | 保留原文 | `{b}<Name>{/b}`、`{b}[name]{/b}` |
   | 所有格 `'s` | **丢掉**，"的"写中文 | `{b}<Name>'s{/b}` → `{b}<Name>{/b} 那儿` |
   | 普通强调词 | **要译**，标签照留 | `{b}CAN{/b}` → `{b}能{/b}`；`{b}NOW{/b}` → `{b}立刻{/b}` |

   - 源文自带的畸形结构（双层嵌套 `{b}{b}<Name>{/b}{/b}`、全大写强调 `{b}<WORD>{/b}`）**结构照抄，不要修**。
   - 纯发声词（`{b}AHHHH{/b}` 这类）按第 8 条原样返回英文。
4. **同一份英文只会有一个译文**（Ren'Py `strings:` 按英文内容全局匹配），重复句必须同译。
5. 中文用全角标点 `，。！？……——`；英文行保持原样。
6. **`[persistent.xxx_role]` / `renpy.input` 插值出来的是玩家自己打的英文词**（housemate / landlady 这类），
   不是术语：**不许翻译、不许替换成中文称呼**，也不许改括号里的变量名。
7. 露骨内容按原文语气直译（见下）。
8. 纯拟声 / 呻吟 / 只有人名的句子（`Mhmmm~`、`Ahhh!!!!`、`Isabel?! Connor?!`）没有可译内容 →
   **原样返回英文**，别硬造中文（生成器检测到译文无 CJK 时只输出原文一行，不会把英文显示两遍）。
9. **`*动作/神态说明*` 要译**，星号保留：`*whispers*` → `*低声*`、`*sarcastically*` → `*讽刺地*`。
   纯拟声（`*Zzzzzz*`、`*GASP*`）按第 8 条不译。

## 输出格式（给 agent 的硬约束，直接决定成本）

- 输出是一个**扁平 JSON 对象** `{"r000001": "…", …}`，一层，无嵌套、无注释。
- **值内部绝对不要出现英文双引号 `"`**（本项目最常见的失败模式：一个裸 `"` 让整份文件解析失败，
  agent 被迫回头修，实测多花 1–11 次工具调用、最高一组 297 万 token）。要引用就用中文引号 `“”`。
- 值内部不要出现裸反斜杠；源文里的 `\%` 这类未知转义要保留时写成 `\\%`。
- 每个 id 必须出现一次，不许多也不缺；id 逐字照抄。
- **一次 `Write` 写完，写完不要回头编辑，不要写校验脚本，不要读真源 JSON。**
- 原文没有换行符就不要加 `\n`。

## 标点细则（钉死，否则 20 个并行 agent 必然分叉）

- 源文 `...`（ASCII 三点）→ 中文 `……`；源文 `…`（单个省略号字符）→ 中文 `…`。**按源文形态区分，不统一**。
- 源文末尾的畸形省略号（`....`、`..`、`….`）**照抄**，不"顺手规范"。
- 打断用的 `--` 保持 `--`，**不改成 `——`**；`——` 只用于拖长音/结巴（`也—也许吧`、`要—我要…`）。
- 主角内心独白若写成 `(...)`：**中文行用全角 `（）`**，括号位置不变，不要改成破折号或斜体。
- 结巴、拖长音（`H-Huh?`、`Maaaybe`、`Wellll`）用中文破折号重复表达，不要译成正常词丢掉结巴。
- 纯语气词按**有没有交际意义**分：有（`Mhm?`＝嗯？、`Uuhh`＝为难）→ 译；
  没有（`Ahhh!!!!`、`NOOOOOOOO!` 单独成行）→ 按第 8 条原样返回。

## 称呼口径

| 英文 | 中文 | 说明 |
| --- | --- | --- |
| `<Ms. Name>` | `<Name> 老师 / 小姐 / 女士` | 按角色关系选，并全篇统一 |
| `ma'am` / 单独称谓 | `您` | 中文敬称不落在名字上时 |
| `Mom` / `Dad` | `妈妈` / `爸爸` | 亲属称谓例外，可以译 |
| `daddy`（性语境） | **保持英文** | 与上面的 `Dad→爸爸` 撞车会造成指代混乱 |
| `<头衔，如 Master>` | `<主人>` | 全篇统一；注意它同时可能是关卡/段位名（`Master tier`→`大师段位`） |

## 专有名词与游戏内标题

- 游戏内的小游戏/节目/栏目名保持英文（本仓 §15 有实例）。
- 品牌、组织、平台、货币写法照原文：虚构平台名 / 社团名保持拉丁，`$5,000` 不改成"五千美元"；
  源文自带的拼写错误照抄。
- **神话与历史人物用通行中文译名**（他们不是本作角色，是台词里的典故）：
  希腊/罗马神名与族名一律用中文通行叫法。间隔号 `·` 用于西方人名音译。
- 大学/机构名：在 UI 里也会出现的保持拉丁；只在散句里出现一次的可以意译。
- **说话人标签 `who` 在源脚本里可能标错**（互换的几行）：**按英文内容判断语气**，不要跟着错误标签走。

## 声线（每个角色的语域必须拉开）

- **<角色 A>** — <身份 + 语域，例：句子短、有权威、爱用命令式；失守后独白变长句、自我拉扯>
- **<角色 B>** — <例：算计型，台词克制，独白情绪外露>
- **<角色 C>** — <例：冲动贫嘴，感叹与口语多；全场语域最低的人，别把她译得聪明>
- **<反派/偏执追求者>** — <用过度礼貌的书面腔说恐怖的话，这种反差是角色本身，不能译成正常人说话>
- **旁白（无说话人）** — 书面文学腔，第三人称，长句与比喻照原样保留，不要口语化。
  新闻播报体要译成中文新闻稿腔。

## 露骨内容

按原文语气直译，不回避、不美化、不改尺度、不用委婉语替代。
这是用户自有游戏的虚构文本本地化，回避翻译会造成剧情断裂。
身体部位、动作、脏话、调教术语都按原强度对应中文口语词，不加星号、不省略。
**同一组近义词要拉开档次**（`boobs`→胸 / `tits`→奶子），原文的粗俗度递进是剧情手段。

## 排版预算（本项目特有）

对白框：`ysize = <N>`px、字号 `<M>`、宽 `<W>`px、`dialogue_ypos <Y>` → 约 `<K>` 行。
**几何一律不动**（§5.2）；塞不下时的唯一手段是 `--text-size` 降 1~2 档，
再塞不下就让它溢出——中文行在上面（`--layout zh-first`），所以"中文一定看得见"自动成立。
数字用 `tools/textbox_fit.py` 出，别估。

字体：游戏自带 CJK 字体 → `--font-mode tag --font-ref <游戏内路径>`（零新增文件）；
没带 → `--cjk-font "C:/Windows/Fonts/NotoSansSC-VF.ttf"`。
**引擎版本不确定时一律用 `tag`**（老引擎没有 `config.font_name_map`，`map` 模式会启动即崩，§6.4）。
脚本里出现过 `{font=}` 显式字体（标题卡、打字机过场）时**必须**用 `tag`，否则全局映射会把它们一起换掉。
