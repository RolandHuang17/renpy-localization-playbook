# <游戏名> — 术语表与翻译基线（模板）

> 复制成 `localization/glossary.md` 后重写。这是每个项目**唯一需要重写的文本**，
> 也是直接喂给翻译执行者（人或 agent）的口径文件。

## 硬约束

1. **人名一律保持英文原样**，不音译、不双语化：`<Name1>` `<Name2>` …
   - ✅ `<Name1> 老师`　❌ `<音译>`　❌ `<Name1> / <音译>`
2. **只译对白**。菜单、设置、导航按钮、HUD、图鉴、标题卡一律不译。
3. `{...}` 文本标签与 `[插值]` 必须原样保留，数量与内容都不能变
   （`tools/apply_trans.py` 会校验标签多重集）。
4. 同一份英文只会有一个译文（Ren'Py `strings:` 按英文内容全局匹配），重复句必须同译。
5. 中文用全角标点 `，。！？……——`；英文行保持原样。

## 称呼口径

| 英文 | 中文 | 说明 |
| --- | --- | --- |
| `<Ms. Name>` | `<Name> 老师 / 小姐 / 女士` | 按角色关系选，并全篇统一 |
| `ma'am` / 单独称谓 | `您` | 中文敬称不落在名字上时 |
| `Mom` / `Dad` | `妈妈` / `爸爸` | 亲属称谓例外，可以译 |

## 声线（每个角色的语域必须拉开）

- **<角色 A>** — <身份 + 语域，例：句子短、有权威、爱用命令式；失守后独白变长句、自我拉扯>
- **<角色 B>** — <例：算计型，台词克制，独白情绪外露>
- **<角色 C>** — <例：冲动贫嘴，感叹与口语多>
- **旁白（无说话人）** — 书面文学腔，第三人称，长句与比喻照原样保留，不要口语化。

## 露骨内容

按原文语气直译，不回避、不美化、不改尺度。这是用户自有游戏的虚构文本本地化，
回避翻译会造成剧情断裂。

## 排版预算（本项目特有）

对白框：`ysize = <N>`px、字号 `<M>`、宽 `<W>`px → 约 `<K>` 行。
双语后超过 `<K>` 行会溢出，因此构建时启用 `--textbox-height <N>`（见手册 §5.1）。
